# IMTS CARE website – local development

This is the first homepage implementation for the IMTS CARE Next.js project.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Notes

- The original supplied IMTS CARE logo is stored at `public/images/imtscare-logo.png`.
- Homepage photography currently uses remote Unsplash image URLs in `src/app/globals.css` as temporary placeholders. Replace these with approved company photographs before launch.
- Contact details and company positioning are based on the supplied IMTS CARE company profile. Please confirm all figures, fleet details, credentials, service availability and contact details with the customer before publishing.
- The enquiry buttons currently open WhatsApp or email. No patient data is collected by this first homepage build.
- No Git repository, hosting account or deployment is configured.
